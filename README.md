# Cara Penggunaan
Untuk Penggunaan -> Euclid(a, b) atau EuclidDiperluas(a, b)

Contoh: EuclidDiperluas(1071, 462)
`Hasil = 21`, dengan `index = 3` | `r = 21` | `q = 7` | `s = -3` | `t = 7` -> selanjutnya r = 0 maka program di hentikan.
